# 日文直播翻譯助手

版本：1.1.0

## X／Twitter 與 Spaces

- X 左下角按「開始日文語音字幕」，將 Spaces 或直播中的日文聲音翻成繁中。
- 音訊使用 Mac 的系統輸出，需選擇「即時字幕＋喇叭」。這不是單獨擷取某個 Space，其他程式的聲音也可能被辨識。
- 貼文與回覆可按「翻成繁中」。
- 在發文或回覆框輸入中文，按「中 → 日 · 親切可愛」，可編輯日文草稿，再按「放入留言框」。由你自行送出。
- 有留言入口時使用該入口；若 Space 沒有留言框，可在相關貼文下回覆。本擴充功能不新增 X 平台沒有的留言入口。
- 加入原創中日語言卡片與音訊波形圖示，提供 16、32、48、128 像素尺寸。

在 YouTube 影片頁與直播聊天室運作：

- 將即時日文語音與繁中譯文直接顯示在影片底部。
- 日文影片標題下方顯示繁體中文。
- 一般留言及直播留言下方顯示繁體中文。
- 在留言框輸入中文，按「中 → 日」後，日文會放回留言框；確認後再按 YouTube 的送出鍵。
- 中翻日採用適合觀眾對 VTuber 留言的親切可愛口語，保留禮貌與原意，不擅自添加親密稱呼或告白。

必須先雙擊桌面的「啟動即時字幕」，因為擴充功能使用同一套本機 Whisper 與 Qwen 模型。點擊瀏覽器工具列的擴充功能圖示，可以開始或停止語音字幕。翻譯內容不會送到 OpenRouter 或 NVIDIA。

## 安裝或更新

1. 解壓縮 ZIP，將資料夾保存在固定位置。
2. 在 Opera GX 開啟 `opera://extensions`，開啟開發人員模式。
3. 按「Load unpacked／載入未封裝項目」，選取含有 `manifest.json` 的 `youtube-translator-extension` 資料夾。
4. 若已從原本專案資料夾載入，只需在擴充功能管理頁按該擴充功能的「Reload／重新載入」。
5. 重新整理 YouTube 頁面。

此 ZIP 僅包含擴充功能；本機語音辨識與翻譯服務仍需使用已安裝的即時字幕程式。瀏覽器實頁驗證尚未完成。
